\begin{abstract}
\begin{tcolorbox}[
  colback=aisoft!70,
  colframe=aideep,
  arc=3pt,
  boxrule=0.8pt,
  left=5pt,right=5pt,top=5pt,bottom=5pt
]
\noindent\textbf{\textcolor{aideep}{Clinical Problem:}} \textbf{Chest radiography (CXR) interpretation is constrained by visual overlap with atelectasis and non-infectious opacities, while imaging alone cannot quantify host systemic inflammation.}

\vspace{3pt}
\noindent\textbf{\textcolor{aideep}{Multimodal Approach:}} \textbf{We present PneumoFusionNet, a progressive multimodal framework evaluated on 3{,}763 frontal PA radiographs from MIMIC-CXR, coupled with radiology reports from MIMIC-III and laboratory records from MIMIC-IV. The framework integrates a NIH-pretrained DenseNet-121 backbone (zero MIMIC pretraining overlap) augmented with CBAM, Bio\_ClinicalBERT token representations fused via 8-head cross-attention with key-padding mask, and a non-linear WBC encoder MLP ($1 \to 128 \to 128 \to 64$). All models share a single stratified patient-level split (70/15/15) with zero patient overlap verified across partitions.}

\vspace{3pt}
\noindent\textbf{\textcolor{aideep}{Anti-Leakage Safeguards:}} \textbf{IMPRESSION sections are stripped; only INDICATION and FINDINGS are retained. No raw-report fallback. All thresholds are selected on the validation set only (Youden's~J) and frozen before test evaluation. Imputation and scaling are fitted exclusively on training data.}

\vspace{3pt}
\noindent\textbf{\textcolor{aideep}{Key Results (562-image test set, 511 patients):}}
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=*]
  \item \textbf{Model A — CXR only (Phase~1):} AUC\,=\,0.808, Sensitivity\,=\,61.7\%.
  \item \textbf{Model B — CXR + Text (Phase~2):} AUC\,=\,0.948, Sensitivity\,=\,87.1\% (+14.0~pp AUC over Phase~1).
  \item \textbf{Model D — CXR + Text + WBC:} AUC\,=\,0.948, Sensitivity\,=\,87.8\%, Specificity\,=\,90.1\%.
  \item \textbf{Phase~3 — CXR + Text + 16 EHR features:} AUC\,=\,0.948, Sensitivity\,=\,88.2\%.
\end{itemize}
\end{tcolorbox}
\end{abstract}

% ==========================================================
%  I. INTRODUCTION
% ==========================================================
\section{\textcolor{aideep}{Introduction}}

Pneumonia remains the leading infectious cause of mortality globally, accounting for approximately 2.5~million deaths annually~\cite{gbd2019}, and is the single largest infectious killer of children under five~\cite{who2023}. Chest radiography (CXR) is the primary screening modality in both high- and low-resource clinical settings; however, solo radiographic interpretation is inherently difficult. Consolidation, ground-glass opacities, and interstitial infiltrates overlap considerably with atelectasis, pleural effusion, pulmonary oedema, and neoplastic disease~\cite{kelly2012}.

\textbf{Deep learning for CXR analysis.} CheXNet~\cite{rajpurkar2017chexnet} demonstrated that a 121-layer DenseNet trained on the NIH ChestX-ray14 dataset could match radiologist-level pneumonia detection performance, achieving an AUC of 0.768 on the pneumonia class. Wang~et~al.~\cite{wang2017chestxray14} released the ChestX-ray14 benchmark enabling comparison across 14 thoracic pathologies. Despite these advances, pure vision models exhibit a performance ceiling because X-rays encode anatomy but not physiology.

\textbf{Multimodal radiology AI.} Alsentzer~et~al.~\cite{alsentzer2019bert} released Bio\_ClinicalBERT, a BERT variant pre-trained on MIMIC-III clinical notes. Zhang~et~al.~\cite{zhang2020contrastive} applied contrastive learning to jointly represent CXR images and report sentences. A critical weakness in most multimodal systems is \emph{label leakage}: reports contain IMPRESSION sections that directly state the diagnosis, and models trained on raw reports learn to read the diagnosis rather than to infer it~\cite{bannur2023knowledge}.

\textbf{Laboratory biomarkers.} The White Blood Cell (WBC) count from a routine CBC is universally available and results arrive within 15~minutes. Elevated WBC (leukocytosis, $>$11{,}000~cells/$\mu$L) is a hallmark of bacterial infection and a natural complement to CXR triage. No prior published system has studied the marginal value of WBC under strict leakage controls on a large credentialled dataset with a shared patient-level split.

\textbf{Contributions.} This paper presents \textbf{PneumoFusionNet}:
\begin{enumerate}[noitemsep, leftmargin=*]
  \item A \textbf{leakage-controlled text pipeline} retaining only INDICATION and FINDINGS, disabling raw-report fallback, and forwarding the BERT attention mask as \texttt{key\_padding\_mask} to cross-attention.
  \item A \textbf{shared patient-level split} (70/15/15 by \texttt{subject\_id}, zero overlap) used identically across all four model configurations, enabling direct comparison.
  \item A \textbf{four-way ablation} (CXR~$|$~CXR+Text~$|$~CXR+WBC~$|$~CXR+Text+WBC) evaluated on the same 562-image held-out test set, with thresholds derived on the validation set only.
  \item A \textbf{clean backbone}: \texttt{densenet121-res224-nih} pretrained on NIH ChestX-ray14 with zero MIMIC pretraining overlap.
\end{enumerate}

% ==========================================================
%  II. RELATED WORK
% ==========================================================
\section{\textcolor{aideep}{Related Work}}

\textbf{Image-only CXR classifiers.} Following CheXNet~\cite{rajpurkar2017chexnet}, numerous architectures have been applied to thoracic disease detection. EfficientNet-based models~\cite{tan2019efficientnet} achieve strong ImageNet transfer but underperform domain-pretrained models on grayscale radiographs. Attention mechanisms such as CBAM~\cite{woo2018cbam} and spatial pyramid pooling have been shown to improve localisation of pulmonary infiltrates.

\textbf{Multimodal image-text systems.} ConVIRT~\cite{zhang2020contrastive} and BioViL~\cite{bannur2023knowledge} use contrastive learning to align CXR embeddings with report sentences, demonstrating substantial zero-shot transfer. These are pre-training frameworks rather than supervised classifiers. Our Phase~2 builds on the supervised cross-attention paradigm, extending it with strict leakage controls not present in prior work.

\textbf{Clinical metadata integration.} Yu~et~al.~\cite{frontiers2025pneumofusion} proposed PneumoFusion-Net combining ResNet-50 with Global Channel-Spatial Attention for multi-class classification on CT imaging. Acosta~et~al.~\cite{acosta2022multimodal} demonstrated that combining imaging with tabular EHR data in a multimodal transformer substantially outperforms either modality alone. Our study is unique in isolating the marginal value of a single rapidly-available biomarker (WBC) with a text-only baseline to disentangle modality contributions.

%  III. DATASET
% ==========================================================
\section{\textcolor{aideep}{Dataset and Experimental Setup}}

\subsection{Data Sources}

Experiments used \textbf{MIMIC-CXR-JPG v2.0.0}~\cite{johnson2019mimic}, a de-identified clinical chest X-ray dataset from Beth Israel Deaconess Medical Centre (BIDMC), paired with free-text radiology reports. Only \textbf{posteroanterior (PA)} radiographs were retained to eliminate view-acquisition bias: AP views correlate with patient acuity (bedside ICU imaging) rather than pathology, creating a shortcut that inflates test AUC.

WBC measurements were extracted from \textbf{MIMIC-IV}~\cite{johnson2023mimiciv} lab records (ItemIDs 51300/51301 in \texttt{labevents}) and linked to radiographic studies via patient identifiers within a $\pm$2-day window. When multiple readings existed, the temporally closest measurement was selected.

\subsection{Patient-Level Split (Experiment 1)}

The full paired dataset contains \textbf{3,763 radiographs from 3,404 unique patients} (1,872 Normal, 1,891 Pneumonia). The split was performed \emph{once} by \texttt{subject\_id} using stratified sampling. The same partition is used for all four model configurations:

\begin{center}
\small
\begin{tabular}{lrrl}
\toprule
Partition & Patients & Radiographs & Balance \\
\midrule
Train & 2,382 (70.0\%) & 2,635 & 1,311 N / 1,324 P \\
Val   &   511 (15.0\%) &   566 &   278 N / 288 P \\
Test  &   511 (15.0\%) &   562 &   283 N / 279 P \\
\bottomrule
\end{tabular}
\end{center}

Verified: Train$\cap$Val\,=\,Train$\cap$Test\,=\,Val$\cap$Test\,=\,$\emptyset$.

\subsection{Backbone Selection (Experiment 2)}

The original design used \texttt{densenet121-res224-all} whose pretraining mixture \emph{includes} MIMIC-CXR, creating overlap between backbone pretraining and our evaluation dataset. We switched to \textbf{\texttt{densenet121-res224-nih}}, pretrained exclusively on NIH ChestX-ray14 with \textbf{zero MIMIC pretraining overlap}.

\subsection{WBC Matching and Missingness}

Of 3,763 radiographs, \textbf{3,029 (80.5\%)} received a matched WBC value within the $\pm$2-day window; \textbf{734 (19.5\%)} were missing and imputed with the \emph{training-set median} ($7.40\times10^9$/L). The imputed value was computed only from the training partition and applied identically to validation and test sets. Because the matching window is retrospective, results involving WBC should be interpreted as an \textbf{exploratory analysis}, not as evidence of real-time ED deployment performance.

%  IV. METHODOLOGY
% ==========================================================
\section{\textcolor{aideep}{Methodology}}

\begin{figure*}[!t]
\centering
\href{architecture.png}{\includegraphics[width=0.85\textwidth]{architecture.png}}
\caption{\textcolor{aideep}{PneumoFusionNet Phase~3 architecture.} Three input modalities (chest X-ray, leakage-free radiology report text using INDICATION+FINDINGS only, and WBC blood count) flow through separate encoder branches. The NIH-pretrained DenseNet-121 image encoder is frozen. The image and text representations interact via 8-head cross-attention (with key\_padding\_mask), then concatenate with the WBC embedding to form a 1{,}600-dimensional feature vector for binary classification.}
\label{fig:architecture}
\end{figure*}

\subsection{Phase~1: Vision Backbone (Model A — CXR Only)}

The image encoder uses \textbf{DenseNet-121}~\cite{huang2017densenet} pre-trained on NIH ChestX-ray14 via the TorchXRayVision~\cite{cohen2022torchxrayvision} library (\texttt{densenet121-res224-nih}), with zero MIMIC pretraining overlap. Images are normalised to the TorchXRayVision intensity range $[-1024, 1024]$, resized to $224\times224$, and enhanced with CLAHE (clip limit 2.0, tile grid $8\times8$). Training augmentation includes random horizontal flip, rotation ($\pm10^\circ$), small translation ($\pm5\%$), and Gaussian blur.

A \textbf{CBAM}~\cite{woo2018cbam} block is appended after the backbone:
\begin{equation}
  \mathbf{F}' = \mathbf{M}_c(\mathbf{F}) \otimes \mathbf{F}, \quad \mathbf{F}'' = \mathbf{M}_s(\mathbf{F}') \otimes \mathbf{F}'
\end{equation}
with channel reduction ratio $r\!=\!16$ and a $7\times7$ spatial convolutional filter. The encoder output is a \textbf{1024-dimensional} global average-pooled feature vector $\mathbf{v}_{\text{img}} \in \mathbb{R}^{1024}$, frozen for all downstream phases.

\textbf{Training:} Single 70/15/15 patient-level split, Focal Loss~\cite{lin2017focal} ($\gamma\!=\!2.0$), AdamW ($\eta\!=\!10^{-4}$, weight decay $10^{-4}$), cosine annealing LR. Threshold $\tau$ selected via Youden's~J on the validation set.

\subsection{Phase~2: Radiology Text Fusion (Model B — CXR + Text)}

\textbf{Anti-leakage preprocessing (Experiment 4).} Reports are parsed to extract the \textbf{INDICATION} and \textbf{FINDINGS} sections only. The IMPRESSION section is explicitly excluded. The raw-report fallback (previously used when section extraction failed) is \textbf{disabled}: 218 of 3,763 reports (5.79\%) returned an empty string after extraction; these are passed as empty token sequences and their count is documented. Text is truncated/padded to 256 WordPiece tokens.

Text is encoded using \textbf{Bio\_ClinicalBERT}~\cite{alsentzer2019bert}; the \textbf{top two transformer layers} are fine-tuned with $\eta_{\text{BERT}}\!=\!10^{-5}$; all lower layers remain frozen. The encoder emits the full token sequence $\mathbf{T} \in \mathbb{R}^{B \times 256 \times 768}$.

\textbf{8-head cross-attention with key-padding mask.} Image features act as queries; textual tokens act as keys and values. The BERT attention mask is forwarded as \texttt{key\_padding\_mask} so that padding tokens do not influence the attended representation:
\begin{equation}
  \mathbf{c}_{\text{cross}} = \text{softmax}\!\left(\frac{\mathbf{Q}_{\text{img}}\mathbf{K}_{\text{txt}}^\top}{\sqrt{d_k}} + \mathbf{M}_{\text{pad}}\right)\mathbf{V}_{\text{txt}}, \quad d_k = 64
  \label{eq:crossattn}
\end{equation}
where $\mathbf{M}_{\text{pad}} \in \{0, -\infty\}^{B\times L}$ masks padding positions. After multi-head pooling: $\mathbf{c}_{\text{cross}} \in \mathbb{R}^{512}$.

The Phase~2 classification head:
\begin{equation}
  [\mathbf{v}_{\text{img}} \,\|\ \mathbf{c}_{\text{cross}}] \in \mathbb{R}^{1536} \xrightarrow{\text{LN} \to 512 \to 128 \to 2} \hat{y}
\end{equation}

\textbf{Training:} Focal Loss ($\gamma\!=\!2.0$), embedding Mixup~\cite{zhang2018mixup} ($\alpha\!=\!0.2$), fusion head lr\,=\,$2\times10^{-4}$, BERT lr\,=\,$10^{-5}$. Early stopping on validation AUC (patience~8). \textbf{Text-only baseline:} A ClinicalBERT-only classifier (no image) achieved AUC\,=\,0.940, confirming that the report text carries most of the predictive signal.

\subsection{Model C: CXR + WBC Only}

A frozen ImageEncoder feeds a concatenation head alongside a WBC MLP ($1\to128\to128\to32$), producing a 1056-d representation for binary classification. This ablation isolates the marginal value of WBC without text.

\subsection{Phase~3: Triple Fusion (Model D — CXR + Text + WBC)}

The WBC scalar is projected through a dedicated non-linear encoder:
\begin{equation}
  \mathbf{e}_{\text{wbc}} = \text{MLP}(\text{wbc}): \; 1 \to 128 \to 128 \to 64
  \label{eq:wbcmlp}
\end{equation}
with ReLU activations and dropout $(p\!=\!0.3, p\!=\!0.2)$. All three embeddings are concatenated:
\begin{equation}
  \mathbf{z} = [\,\mathbf{v}_{\text{img}} \,\|\, \mathbf{c}_{\text{cross}} \,\|\, \mathbf{e}_{\text{wbc}}\,] \in \mathbb{R}^{1600}
  \label{eq:concat}
\end{equation}

Classifier head: LN$(1600) \to$ Drop$(0.4) \to 512 \to$ Drop$(0.3) \to 128 \to$ Drop$(0.2) \to 2$.

\textbf{Warm-start:} Phase~3 loads the Phase~2 checkpoint, preserving cross-attention alignment. Differential learning rates: BERT\,=\,$10^{-5}$, fusion head\,=\,$2\times10^{-4}$, WBC encoder\,=\,$10^{-3}$.

\textbf{Extended Phase~3 (16 EHR features):} In addition to WBC, 15 structured clinical features (age, gender, vital signs, lab values) are incorporated via a metadata MLP ($16\to128\to128\to64$). \texttt{is\_deceased} is explicitly excluded. Median imputation and StandardScaler are fitted \emph{only} on training data.

\textbf{Threshold calibration:} All thresholds are selected on the \textbf{validation set only} using Youden's~J ($\tau^* = \arg\max_\tau[\text{TPR} - \text{FPR}]$), then frozen before any test-set evaluation.

% ==========================================================
%  V. ANTI-LEAKAGE PROTOCOL
% ==========================================================
\section{\textcolor{aideep}{Anti-Leakage Protocol}}
\label{sec:antileak}

Radiology reports contain an IMPRESSION section that directly states the radiologist's diagnosis. Models trained on raw reports achieve artificially high performance by memorising this conclusion~\cite{bannur2023knowledge}. PneumoFusionNet enforces the following safeguards:
\begin{enumerate}[noitemsep, leftmargin=*]
  \item \textbf{Section Filtering:} Only INDICATION and FINDINGS sections are retained. IMPRESSION/CONCLUSION sections are stripped via regex. \textbf{No raw-report fallback.}
  \item \textbf{Empty Report Handling:} 218 of 3,763 reports (5.79\%) returned empty after extraction; these are passed as empty token sequences, documented, and not silently replaced with the full report.
  \item \textbf{Key-Padding Mask:} The BERT attention mask is forwarded as \texttt{key\_padding\_mask} to the cross-attention layer, preventing padding tokens from influencing attended representations.
  \item \textbf{Patient-Level Splitting:} All partitions enforce strict grouping on \texttt{subject\_id} (GroupShuffleSplit). Zero patient overlap verified: Train$\cap$Val\,=\,Train$\cap$Test\,=\,Val$\cap$Test\,=\,$\emptyset$.
  \item \textbf{Train-Only Imputation:} Missing WBC values (19.5\%) imputed using training-set median only; StandardScaler fitted on training data only.
  \item \textbf{Validation-Only Thresholds:} All classification thresholds determined on the validation set; test set remains unseen until final evaluation.
  \item \textbf{is\_deceased Excluded:} This field encodes the clinical outcome rather than a pre-diagnosis observation and is permanently removed from all feature sets.
\end{enumerate}

% ==========================================================
%  VII. DISCUSSION
% ==========================================================
\section{\textcolor{aideep}{Discussion}}

\textbf{Image-only models plateau at AUC\,$\approx$\,0.81.} Despite CBAM attention and a clean NIH-pretrained backbone, the vision model saturates at AUC\,=\,0.808 with Sensitivity of only 61.7\%, missing more than a third of pneumonia cases. This confirms that visual morphology alone is insufficient.

\textbf{Radiology text is the dominant modality.} The text-only ClinicalBERT baseline reaches AUC\,=\,0.940, only 0.8~pp below the full CXR+Text model. This high correlation between report text and diagnosis labels in MIMIC-CXR is expected (the same radiologist writes both), and underscores the importance of the leakage-controlled preprocessing: performance reflects genuine text features (symptom history, clinical observations), not memorised diagnosis strings.

\textbf{Cross-attention with key-padding mask improves text integration.} Forwarding the BERT attention mask as \texttt{key\_padding\_mask} prevents the model from attending to padding positions, ensuring that the 218 empty-report cases (5.79\%) receive properly zeroed-out cross-attention outputs rather than noisy attended embeddings.

\textbf{WBC provides marginal but consistent lift.} Model~D (CXR+Text+WBC, AUC\,=\,0.948) marginally outperforms Model~B (CXR+Text, AUC\,=\,0.948) in accuracy (+0.9~pp), specificity (+1.0~pp), and F1 (+0.009). However, the retrospective nature of WBC matching ($\pm$2-day window) means that pre-index WBC availability in a true real-time ED setting requires prospective validation.

\textbf{Limitations.} All data originate from a single US institution (BIDMC). Approximately 19.5\% of WBC values required median imputation. The binary classification formulation does not address multi-label co-morbidities. External validation on diverse populations and scanner hardware is necessary before clinical deployment.

% ==========================================================
%  VIII. CONCLUSION
% ==========================================================
\section{\textcolor{aideep}{Conclusion}}

We presented PneumoFusionNet, a leakage-controlled progressive multimodal framework for pneumonia detection on 3{,}763 MIMIC-CXR studies. Using a single stratified patient-level split (70/15/15 by \texttt{subject\_id}) and evaluating all models on an identical 562-image test set with validation-derived thresholds, we quantified the contribution of each modality. The image-only baseline (AUC\,=\,0.808) is substantially improved by leakage-free radiology text fusion (AUC\,=\,0.948, +14.0~pp), while WBC addition provides a small marginal gain. The text-only baseline (AUC\,=\,0.940) confirms that the report is the dominant modality. Future work will investigate prospective pre-index WBC matching, external validation on geographically diverse datasets, and multi-label pathology classification.
