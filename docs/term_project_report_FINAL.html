Abstract — This report presents PneumoFusionNet, a multimodal deep learning framework for precise pneumonia diagnosis, inspired by the PneumoFusion-Net paper of Yu et al. (2025) [2] and built on the restricted MIMIC-CXR hospital dataset. The research progressed through four stages: (1) Architecture validation on public datasets — Kaggle Chest X-Ray (92% accuracy) and the Indiana University (IU) dataset (multimodal pipeline prototype); (2) Dataset search and access — After evaluating multiple public datasets, MIMIC-CXR was selected as the only dataset with paired X-ray images, clinical history, and radiological reports; access required CITI training and a PhysioNet Data Use Agreement (DUA); (3) Pilot study — A 139-sample pilot with ResNet50 + DSC + GCSA showed promising results, with leakage-free text fusion yielding +3.7% AUC over the image-only model; (4) Scale-up failure — Scaling to 1,989 PA-only images, the identical pilot architecture failed completely (AUC = 0.713, Accuracy = 66.2%), proving ImageNet-pretrained models are insufficient for clinical-scale CXR classification. The conclusion motivates a complete pivot to DenseNet-121 with domain-specific X-ray pretraining for the final stage.
Index Terms — Multimodal Deep Learning, MIMIC-CXR, Bio_ClinicalBERT, ResNet50, Depthwise Separable Convolution, Global Context Spatial Attention, Label Leakage, Pneumonia Detection.
1. Introduction

Pneumonia is one of the leading causes of death worldwide, responsible for approximately 2.5 million deaths annually [1]. Chest radiography (CXR) is the primary diagnostic tool because it is fast, affordable, and universally available. However, reading a chest X-ray is highly challenging due to visual ambiguity: the same cloudy patch in a lung can look like pneumonia, fluid buildup (pleural effusion), or a collapsed lung section (atelectasis). Even experienced radiologists sometimes disagree.

Image-only AI models ignore the clinical context that every doctor uses — symptoms, medical history, and test results. Adding radiology report text should help, but introduces a critical trap:

⚠ What is Label Leakage?
Every radiology report ends with an IMPRESSION section containing the doctor's final written diagnosis. If a model reads this during training, it simply memorises the answer instead of learning to diagnose. We strip this section completely:

✔ INDICATION: Patient with fever and cough. → Used for training
✔ FINDINGS: Consolidation in left lower lobe. → Used for training
✘ IMPRESSION: Pneumonia confirmed. → REMOVED before training

This project builds PneumoFusionNet, inspired by the multimodal approach of Yu et al. [2], and tested on the restricted MIMIC-CXR clinical database [3]. Sections 2–6 cover: public dataset experiments, dataset search, anti-leakage methodology, pilot results, and the scale-up failure. Section 7 concludes.

2. Stage 0: Architecture Validation on Public Datasets

Before accessing restricted clinical data, we designed and validated a custom pilot architecture on publicly available datasets.

2.1 Pilot Architecture: ResNet50 + DSC + GCSA

ResNet50 Backbone [4]. A ResNet50 pretrained on ImageNet serves as the feature extractor. The first convolutional layer is adapted for single-channel grayscale X-ray input by averaging the pretrained RGB weights. The first seven children are frozen during training.

Depthwise Separable Convolution (DSC). Compresses the 2048-channel ResNet50 output to 1024 channels with ~50% fewer parameters than a standard convolution:

DSC(X) = BN(ReLU(W1×1 ∗ (Wdw ⊛ X)))

Global Context Spatial Attention (GCSA). Combines channel and spatial attention to focus the model on pathologically relevant lung regions:

Ach = σ(MLP(AvgPool(X)) + MLP(MaxPool(X)))
Asp = σ(Conv7×7([AvgCh(X); MaxCh(X)]))
X̂ = X · Ach · Asp

3. Dataset Search and Securing MIMIC-CXR
3.1 The Dataset Problem

After completing Stage 0, we identified a critical gap: no publicly available dataset simultaneously provides all three required modalities:

  1. Chest X-ray images.
  2. Clinical data (symptoms, medical history).
  3. Unstructured radiological reports with distinct FINDINGS and IMPRESSION sections.

Kaggle has only images. The Indiana University (IU) dataset has images and reports but lacks clinical depth and realistic imbalance. After evaluating NIH ChestX-ray14, CheXpert, and PadChest, we identified MIMIC-CXR-JPG (v2.0.0) as the ideal dataset [3].

4. Methodology: Anti-Leakage Pipeline and System Design
4.1 Anti-Leakage Data Preparation

We developed rebuild_dataset_findings.py, which processes each MIMIC-CXR radiology report and:

  1. Parses the report into named sections (regex-based).
  2. Retains: INDICATION/HISTORY and FINDINGS (pre-diagnosis evidence).
  3. Strips: IMPRESSION and CONCLUSION (the written diagnosis).
  4. Outputs filtered text to a cleaned CSV for training.

Three CSV files manage the pipeline: mimic_dataset.csv (image-only), mimic_multimodal_dataset.csv (image + raw text), and mimic_multimodal_dataset_v3.csv (image + leakage-free text).

5. Stage 1: MIMIC-CXR Pilot Study (139 Samples)
5.1 Pilot Dataset

Due to the massive size of MIMIC-CXR, we started with a small pilot subset (extracted from the P10 directory) to verify our pipeline and anti-leakage filters: 139 total samples (118 Normal, 21 Pneumonia; 5.6:1 class imbalance). All view types (PA, AP, Lateral) were included. Row-level stratified 70/15/15 split: 97 train / 21 val / 21 test.

On the imbalanced (realistic) split, adding leakage-free clinical text improved AUC by +3.7% and accuracy by +4.8%. This gain is genuine — IMPRESSION was never shown to the model.

5.3 Statistical Honesty: The N=7 Problem

The balanced pilot test set had exactly 7 samples. One misclassification causes a 14.28% accuracy swing. Computing 95% CIs using CI = p ± 1.96√(p(1−p)/N):

  • Phase 1.1 CI: 85.7% ± 25.9% → [59.8%, 100%]
  • Phase 2.1 CI: 71.4% ± 33.5% → [38.0%, 100%]

A Fisher's Exact Test yields p ≈ 1.000. The 14.3% difference is statistically insignificant. The AUC of 0.917 on N=7 samples is meaningless. We must scale up to get a reliable answer.

6. Stage 2: Scale-Up Dataset and Architecture Failure
6.1 Scale-Up Data Preparation

We curated a larger dataset of 1,989 PA-only images from MIMIC-CXR (1,062 Normal + 927 Pneumonia) with two critical improvements over the pilot:

  • PA-only filtering: Restricting to Posteroanterior views eliminates the view-type confound. AP views (patient supine) have different anatomical proportions that could confound the classifier.
  • Patient-level splits: GroupShuffleSplit by subject_id guarantees zero patient overlap: 1,401 train / 295 val / 293 test.

❌ Root Cause Analysis: Why the Architecture Failed
  1. ImageNet domain mismatch. ResNet50 was pretrained on 1.2M natural images (cats, dogs, cars). Low-level features from natural images are fundamentally mismatched with the subtle opacity differences and air bronchograms in chest X-rays.
  2. Insufficient data for domain transfer. 1,401 training images cannot adequately override 1.2M images of ImageNet pretraining to learn clinical pathology from scratch.
  3. Clinical data complexity. Real MIMIC-CXR images contain medical devices, overlapping bones, varying scanner exposures, and positioning artefacts entirely absent from pre-cleaned Kaggle data.
7. Discussion and Conclusion
7.1 Key Findings
  • Public benchmarks ≠ clinical performance. 92% on Kaggle collapsed to 66.2% on real MIMIC-CXR data. High public-dataset performance gives dangerously false clinical confidence.
  • The anti-leakage text pipeline works. Leakage-free text fusion provided a genuine +3.7% AUC improvement. FINDINGS + INDICATION contain real diagnostic signal beyond visual features.
  • Small test sets are statistically meaningless. AUC=0.917 on N=7 had CI [59.8%, 100%]. The honest N=293 result is AUC=0.713. Documenting this gap is the most important scientific result of Part 1.
  • The ResNet50+DSC+GCSA architecture must be discarded. ImageNet pretraining is fundamentally insufficient for clinical-scale CXR classification.
7.2 Limitations
  • Single institution (Beth Israel Deaconess Medical Center).
  • Binary classification only (Normal vs. Pneumonia); clinical radiology involves 14+ thoracic findings.
  • No external validation on NIH ChestX-ray14 or CheXpert.
  • Text fusion was only tested on 139-sample pilot, not at clinical scale.
7.3 Conclusion and Part 2 Roadmap

Part 1 delivered three contributions: (1) a robust anti-leakage data preparation pipeline; (2) rigorous proof that public-dataset results do not translate to clinical environments; and (3) the discovery that ResNet50+DSC+GCSA fails at clinical scale (AUC=0.713), motivating a complete architectural pivot.

✅ Part 2 Roadmap — The Solution
  1. DenseNet-121 [5] from torchxrayvision, pretrained on >500,000 actual CXRs (CheXpert, NIH, MIMIC-CXR) — directly solving the domain-mismatch failure.
  2. Scale to 1,989+ PA images with patient-level GroupShuffleSplit.
  3. Multimodal fusion at scale: Bio_ClinicalBERT + cross-attention fusion.
  4. Phase 3: Triple-modality fusion incorporating MIMIC-IV lab values (WBC, CRP, Procalcitonin).
  5. 5-fold GroupKFold cross-validation for robust statistical evaluation.
